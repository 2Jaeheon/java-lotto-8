# java-lotto-precourse

# 기능 요구 사항 목록

## 금액 입력

- [ ] 사용자로부터 구입 금액을 입력 받는다
- [ ] 구입 금액에 해당하는 로또 개수를 계산한다
- [ ] 구입한 로또 개수를 출력한다
- [ ] 각 로또의 번호를 오름차순으로 출력한다

## 로또 생성

- [ ] LottoSeller는 입력받은 금액에 따라 로또 발행을 요청한다
- [ ] LottoIssuer는 유효한 Lotto를 N장 발행한다

## 당첨 번호 입력

- [ ] 사용자로부터 당첨 번호 6개를 입력 받는다
- [ ] 사용자로부터 보너스 번호를 입력 받는다
- [ ] 번호 중복과 범위 체크를 수행한다

## 당첨 결과 계산

- [ ] LottoResultCalculator는 각 로또의 번호를 당첨 번호와 비교한다
- [ ] 일치 개수에 따라 Rank를 결정
- [ ] Rank별로 개수를 계산한다
- [ ] 총 수익률을 계산한다

## 출력

- [ ] 당첨 통계를 출력한다.
- [ ] 수익률을 소수점 둘째 자리에서 반올림하여 출력한다
